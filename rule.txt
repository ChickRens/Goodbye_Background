This file is the spec. Keep it in sync with the implementation (last synced: 2026-11).

Flow

user: Send Image
serv: Create Session

user: Add Point (optional)
serv: Generate Mask & Send cropped Mask

user: Add Point
serv: Generate Mask & Send cropped Mask

...

user: Undo
serv: Send previous Mask & Delete latest Point

...

user: Redo
serv: If exist next history, Send next Mask & Add next Point

...

user: Save Image
serv: Send full-resolution cropped Image
     (Session is NOT deleted on save. It expires like any other data: 10 min after last access)


Rule

Session:
    PNG Image
    Mask history

    Life span is 10 min from the last access   (src/config.rs: TTL_SEC)
    Every read/update resets the life span
    Expired data is removed by GC every 60 sec  (src/config.rs: CLEANUP_INTERVAL)
      -> data lives at most about 11 min after the last access
    Saving is just another access (no special deletion after save)
    All data is in memory: restarting the server deletes everything

History:
    Point array
    current history index

    Redo
    Undo

    If Redo or Undo, Re-Generate Mask from Points

Image:
    Allowed Format (detected from content, not from extension):
        JPEG,PNG,WebP,GIF,BMP,TIFF (and other formats decodable by the `image` crate)
        HEIC/HEIF are NOT supported
    
    Size:
        2<=x<=8000, 2<=y<=8000   (src/image/image/size.rs: MAX_DIMENSION)

    apply:
        Using Mask Extract Image 

Mask:
    Same parent Image Size
